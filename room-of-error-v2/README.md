# Room of Error — 복강경 담낭절제술 후 안전위험 및 이상징후 인지

시뮬레이션테크놀로지Ⅱ 2조(오선영 · 이새롬 · 황인경) 팀 프로젝트의 웹 프로토타입입니다.
수술 당일 병동 복귀 1시간 후 환자의 병실에 숨어 있는 **8개의 안전 오류**를 10분 안에 찾아 교정하고, 재사정 결과를 담당의에게 **SBAR**로 보고하는 Room of Error 시뮬레이션입니다.

- 설계 기틀: NLN Jeffries 시뮬레이션 이론 (학습목표 · 충실도 · 문제해결/복잡성 · 학습자 지원)
- 시나리오 근거: 2조 보고서 개정판 (오류 10개 → 8개, 출혈·통증 트랙 분리, 동료 평정 S-CVI/Ave 0.94)
- 디브리핑은 과제 범위에서 제외되어 구현하지 않았습니다. 종료 후에는 결과 요약과 탐색 로그만 제시합니다.

## 실행 방법

1. **바로 실행**: `index.html`을 더블클릭하면 브라우저(Chrome·Edge 권장)에서 열립니다. 설치할 것은 없습니다.
2. **GitHub Pages로 공유**: 저장소 Settings → Pages → Branch를 `develop`(또는 `main`), 폴더를 `/ (root)`로 지정하면 `https://<계정>.github.io/<저장소>/room-of-error-v2/` 주소로 열립니다.
   - 비공개(private) 저장소에서 Pages를 쓰려면 GitHub 유료 플랜이 필요합니다. 무료 계정이면 `index.html`을 내려받아 열면 됩니다.
3. **테스트용 배속**: 주소 끝에 `?speed=10`을 붙이면 시간이 10배 빠르게 흐릅니다(3·5·8분 이벤트 확인용). 실제 수행 시에는 붙이지 않습니다.

## 진행 흐름

1. **프리브리핑 화면** — 진행 규칙, 심리적 안전 안내, 인계 내용, 학습자 이름·역할 입력
2. **병실 탐색(10분 00초)** — 사물·환자·보호자를 눌러 관찰 소견을 확인하고
   - `이상 보고` → 근거 선택 (적절한 근거면 전점, 부적절하면 50%)
   - `간호 행동` → 교정 수행 (clamp 개방, bulb 압축, 속도 교정, cuff 제거 등)
   - `담당의 전화(SBAR)` → 1분 이내 보고, 누락 시 담당의가 되물음
3. **결과 화면** — 총점, 오류 식별률, 오류별 탐지·조치 시각, 체크리스트, SBAR, 위양성, 탐색 로그 지표. CSV·JSON으로 내려받기. 통과 기준 미충족 시 재시행 1회

탐색 중에는 누적 탐지 수(n/8)를 보여주지 않습니다(정답 노출 방지).

## 오류 8개 (보고서 3-2)

| E2 | JP 선홍색 배액 급증(20 → 100 mL 이상)·우상복부 bloody oozing | 상 | 10 | 5분 | 수술부위 dressing, JP drain |

## 환자 상태 변화 (보고서 3-5)

출혈 트랙(E2)과 통증 트랙(E5)을 분리해 계산합니다. SpO₂는 전 구간 96%로 유지합니다.

| 시점 | 조건 | BP | PR | RR | NRS |
|---|---|---|---|---|---|
| 0분 | 기준 | 140/80 | 88 | 18 | 6 |
| 3분 | E5 미교정(통증 트랙) | 150/95 | 98 | 18 | 7 |
| 5분 | 출혈 트랙 미조치 (+통증) | 130/90 | 110 | 24 | 7 |
| 5분 | 출혈 트랙 미조치, E5만 교정 | 120/75 | 100 | 24 | 6 |
| 8분 | 출혈 트랙 미조치 | 90/60 | 120 | 28 | — |
| 회복 | 5~8분 사이 bolus 시작 → 1분 후 | 136/88 | 100 | 20 | — |
| 회복 | 8분 이후 bolus 시작 → 1분 후 | 100/64 | 108 | 24 | — |

- **출혈 트랙 조치** = E2 SBAR 보고 완료 → 담당의 구두처방(Plasma 500 mL bolus, 이후 80 mL/hr 유지) → 수액조절기에서 **read-back** → **bolus 시작**. 5분 이전에 마치면 5·8분 악화가 적용되지 않습니다.
- E3·E4·E6·E7·E8은 활력징후를 바꾸지 않습니다. E8을 8분까지 교정하지 않으면 8분에 환자가 일어나려 할 때 낙상 위험 이벤트가 기록됩니다.
- 시간 단서: 2분 보호자 등장 · 5분 E5 미탐지 시 보호자가 PCA를 가리킴(이후 E5 탐지 50%) · 8분 남은 시간 2분 경고(전원) · 8분 출혈 트랙 미조치 시 저혈압·빈맥 알람

## 채점 (보고서 6-1)

- **오류 탐지 65점** — 발견 + 적절한 근거 = 전점, 근거 부적절 = 50%. E2는 근거와 담당의 보고까지 해야 전점. 5분 단서 이후의 E5, 담당의 수액 지시 이후 처음 확인한 E4는 50%
- **필수 중재 체크리스트 35점** — C1~C10 달성 수 ÷ 10 × 35
- **가산점** — 5분 이내 E2(탐지+보고)·E3·E5(탐지+교정) 각 +2, 최대 +6
- **위양성 감점** — 1건당 −2, 최대 −10
- **통과** — 총점 80점 이상 + 식별 7/8 이상 + E2·E3·E4·E5·E8 모두 탐지 (미충족 시 재시행 1회)

| C# | 필수 중재 |
|---|---|
| C1 | 손위생 후 개방형 질문과 2가지 식별정보로 환자 확인, 손목밴드 재부착 요청 |
| C2 | 적절한 상지(Rt. arm)에서 V/S·SpO₂ 측정, NRS 사정 (Lt. arm으로 측정하면 미충족) |
| C3 | dressing과 JP drain 배액 양·색·양상 사정 |
| C4 | JP bulb 압축(음압)·line 피부 고정 |
| C5 | 침상머리 semi-Fowler’s(30~45°) |
| C6 | 수액 80 mL/hr 교정 |
| C7 | Lt. arm BP cuff 제거 후 적절한 부위에서 측정 |
| C8 | PCA clamp 개방 및 bolus 사용법 교육 |
| C9 | side rail 상승·call bell 비치 |
| C10 | SBAR 보고 1분 이내, V/S·NRS·배액량 포함 |

탐색 로그 지표(최초 탐지 시간, 권장 동선 9단계 일치도, 불필요 반복 횟수)는 점수에 넣지 않고 성찰 자료로만 보여줍니다.

## 수정할 때

`index.html` 안의 `<script>` 첫 블록 `window.SCN = { ... }`에 시나리오 데이터(환자정보, 활력징후 값, 대사, 오류 근거 보기, 체크리스트, Order Sheet)가 모여 있습니다. 수치나 대사를 바꿀 때는 이 부분만 고치면 됩니다. 두 번째 `<script>` 블록이 시간 진행·판정·채점 엔진입니다.
